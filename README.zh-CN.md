# VVA Agent — 随身在手机，伸手到电脑

[English](README.md)

**我想把 AI 工作台装进口袋，于是做了 VVA Agent。**

**On your phone. Within reach of your PC.**

平时，它住在你的 Android 手机里，帮你查资料、整理文件、写脚本、操作应用。

需要处理电脑上的事情时，接上一根 USB，插上 U 盘——它就能在你的授权下接手软件操作、读取日志、排查问题。

**一部手机，一根线，一枚 U 盘。带走的不只是文件，还有能接着干活的助手。**

VVA 不需要注册自己的账号，也没有 VVA 云端控制中转。记录留在你的设备上，模型由你选择；使用云端模型时，相关任务内容仍会发给供应商。

## 为什么是 VVA

- **不用注册 VVA 账号，没有 VVA 云端中转。** 手机与电脑之间走 USB，对话、任务档案和操作记录保存在你的设备或所选工作区。使用云端模型仍需要手机联网，任务内容会按请求发送给模型供应商。
- **模型由你决定。** 自己选择供应商、配置 API Key。到另一台电脑上工作时，无需在那里配置模型账号和密钥。
- **做过的事，不必总从头摸索。** 操作卡、脚本和任务档案可以保存在本地，供后续检索和复用。重复任务有机会减少试错；软件改版和界面变化仍可能需要重新定位。
- **免费使用。** 模型调用费用由你选择的供应商另行计算。

## 它能做什么

- 在手机上阅读页面、查找信息、操作应用，处理你导入的图片和文件。
- 通过 USB 操作 Windows 电脑：在多个窗口间查找内容、填写文本、调整设置。
- 编写并运行脚本，分析日志，批量处理文件，协助排查软件问题；需要时调用你授权的排查工具。
- 整理资料、保存工作进度、设置定时任务。
- 把结果、证据和交接记录留在工作区，新对话可以检索这些档案，接续已保存的工作。

用途不必止于这份清单。欢迎带着自己的任务来试，也欢迎反馈缺少的功能和不顺手的地方。

任务进行中，你可以继续发消息、补充条件、要求重评或停止任务。悬浮框把交流留在手边，工具调用细节折叠在详情里。停止会中断后续执行，已经提交到目标软件的操作不会因此自动撤销。

## 快速开始

需要 **Android 11 或以上**、一根可传数据的 USB 线，以及 **Windows 10/11 x64** 电脑。U 盘包自带 Python 和 ADB，电脑无需另装 Python。

### 先选下载组合

| 渠道 | 本体包 | U 盘包 |
| --- | --- | --- |
| 官方直接下载 | `01-*.apk`：安装到手机 | `02-*-USB-zh-CN.zip`：完整 U 盘目录，解压即备齐 |
| 转载渠道 | `03-*-Redistribution-Main-zh-CN.zip`：含 APK 与补充文件 | `04-*-Redistribution-USB-zh-CN.zip`：只有启动、终止脚本 |

**普通用户选 `01 + 02` 即可，不用全部下载。** 英文 U 盘包选同组的 `-en.zip`；中英文各选一种即可。本体 APK 自带语言选择。

转载包需选同版本、同语言的 `03 + 04`：分别解压后，把 `VVA-Main/usb-payload/` **里面的全部内容**复制到 `VVA-USB/`，与启动、终止脚本放在同一层。不要把 `usb-payload` 整个目录再套进去。`04` 包很小是正常的，因为它只有两个脚本。完整操作见 [U 盘使用说明](USB.zh-CN.md)。

`90` 是许可资料，`99-SHA256SUMS.txt` 是文件校验表；它们放在下载列表最后，许可资料也已包含在本体和 U 盘包里。

1. 从官方 [Releases](https://github.com/sunnyfox-qinghu/VVA/releases) 获取匹配版本的 APK 和完整 U 盘包。
2. 安装 APK，在 App 中选择模型供应商，填入自己的 API Key。
3. 将完整 U 盘包解压到 U 盘中的可写文件夹，不要在压缩包预览里直接运行。
4. 在手机系统设置中开启开发者选项和 **USB 调试**。接上电脑后解锁手机，接受该电脑的调试授权。
5. 在你拥有或已获授权的电脑上，插好 U 盘和 USB 线，运行 `启动.cmd`，输入 `START`，按需授权桌面控制或命令执行，并选择正确的手机。工作期间保持连接和启动窗口。
6. 用完后按启动窗口中的 **S**，或运行 `终止.cmd`；异常退出后可运行 `清理.cmd`。英文包对应 `Start.cmd`、`Stop.cmd`、`Clean.cmd`。

操作手机自身界面需要无障碍服务；使用悬浮框需要“显示在其他应用上层”权限。长任务、定时任务还需按系统提示配置通知、后台运行及相应闹钟权限。仅通过 USB 操作电脑不要求开启手机无障碍服务。

详细步骤、权限与常见问题见 [U 盘使用说明](USB.zh-CN.md)。不用时可以关闭 USB 调试；不要在不信任的电脑上授予调试权限。

## 怎样让它更快

VVA 的名字来自 VVA-14。为了对得起这个名字，我们打磨了设备操作中的不同路径：

- 能直接读取控件文字时，优先读取；适合后台脚本的工作交给脚本，需要看画面时使用截图、OCR 和局部裁剪。
- 电脑端支持语义定位、元素索引、批量动作、后台窗口读取和操作回执。
- 对支持回读的输入核对结果，切换窗口时校验目标，连接恢复后先检查实际状态，减少误操作和重复提交。

目标很朴素：少截图、少重复找位置、少无效往返，让助手更快弄清楚“现在到了哪一步”。

手机本身也参与工作：本地计算、整理资料和后台任务可以在手机上完成。数据已经在电脑上时，可以让电脑就地处理，只传回需要的结果。

## ⚡ 小闪电（实验性）

开启后，主 Agent 可以按需分派独立子任务，并在设备资源允许时提高本地计算并发，让分析、计算和等待重叠进行。设备键鼠操作仍由主 Agent 协调。

| 方案 | 中位耗时 |
| --- | ---: |
| 单 Agent 一次批处理 | 约 39.3 秒 |
| 三个子 Agent（小闪电） | 约 29.5 秒 |

这是**修订 73 的一次小样本对比**：同一台手机、DeepSeek Flash、max 思考档位，完成相同四项独立数据处理任务，每组两次；产出与独立答案核对通过。计时针对预先安排的计算批次，不含主模型额外规划与汇总。不是所有任务都能拆分，也不代表其他模型会有同样收益。测试明细见 [性能记录](BENCHMARKS.md)。

小闪电可能增加模型用量、耗电和发热，请按任务需要开启。

## 隐私：工作台在手里，资料由你掌握

**VVA 不要求你把私人工作台搬到我们的云端。没有 VVA 账号、VVA 托管的聊天存储，也没有转发手机与电脑操作的 VVA 服务器。**

- **控制链路留在本地。** 手机与电脑通过 USB 通信，电脑伴生程序监听本机回环地址，设备控制无需经过 VVA 云端中转。
- **记录保存在自己的设备上。** 对话、任务档案、证据与操作记录留在手机或你选择的工作区；你可以自行管理、备份和清理。保存在 U 盘工作区的资料可以随盘带走。
- **模型密钥保存在手机。** API Key 使用 Android Keystore 支持的加密存储；正常配对流程不需要把模型账号或密钥配置到目标电脑。
- **不用在电脑安装常驻服务。** 伴生程序按会话启动，不注册 Windows 系统服务或开机自启；结束时可停止本次连接。

**“本地运行”不等于“云端模型看不到任务内容”。** 使用云端模型时，参与任务的消息、文件内容、截图和工具结果仍可能发送给你选择的供应商，并适用其数据政策。VVA 不提供云端中转，也不能替模型供应商承诺数据保留方式。

OCR 在设备上进行，但所用 SDK 可能发送运行指标，具体见 [隐私说明](PRIVACY.md)。使用过的工作区可能包含敏感资料；分享时请使用干净发布包，公开反馈前先脱敏。

## 安全与权限

- **只在你拥有或已获授权的设备上使用。** 普通任务不需要手机 Root 或 Windows 管理员权限。
- **需要管理员作业时，明确范围。** 使用 `启动-管理员.cmd`（英文包为 `Start-Administrator.cmd`），由你确认 Windows UAC。完全信任和 Approve for me 不等于系统管理员权限。
- **从官方渠道获取。** VVA 可以执行高权限操作，请核对来源、版本和签名信息，见 [签名说明](SIGNING.md)。
- **结束会话，保留成果。** `终止.cmd` 停止本包伴生程序、释放本会话通道并清理其临时状态；工作区、报告和手机对话保留。它不会清除操作系统或第三方软件的所有日志、缓存和修改，也不承诺“无痕”。清理未完成时会给出提示。
- **写下保护规则。** 重要资料的使用要求可以放进 SOUL、技能或任务说明，例如“不要修改这个目录”“覆盖文件前先保留副本”“不要把这份资料发给云端模型”。同时使用权限设置和备份；文字约定不能替代它们。不要把密码、密钥放入公开反馈。

## 按你的方式塑造它

- 调整 **SOUL**，编写**技能**、配置 **Hooks**，或安装兼容的插件。桌面插件的原生依赖不一定适用于 Android。
- 在 U 盘中准备 `tools-pack-for-model` 文件夹，放入希望它使用的工具、脚本和说明。开启“完全信任”后，工具箱调用入口向模型开放。你可以修改随包提供的模板，也可以指定其他同名目录。第三方工具可能需要另行下载或接受其许可。
- 可以让模型编写、测试脚本扩展，再按授权启用或回退。这与自动修改、重新编译或升级整个 App 不同；后者不作为当前发布能力。
