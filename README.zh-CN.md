# VVA

[English](README.md)

**发布准备中：仓库保持私有，安装包尚未正式对外发布。**

VVA 将手机、USB 和随盘工作区结合：Android 端运行 Agent，Windows 伴生程序提供桌面操作和后台工具。
项目基于 Hermes，新增了 VVA 的移动端、USB 控制和工作流能力。当前免费使用，开发源码暂不公开。
模型供应商和 API Key 由用户配置，模型调用费与 VVA 免费分发是两回事。

本仓库只放发布说明与发布草稿，不上传开发工程、个人记录或签名私钥。
正式版会提供签名 APK 和中英文完整 U 盘包；转载使用单独的分装版本，见 [分发约定](DISTRIBUTION.md)。

# VVA U 盘伴生包

手机作为 Agent 终端，通过 USB 操作 Windows 电脑，并将作业保存在随盘工作区。包内带 Python 和 ADB，电脑不用另外安装 Python。

## 使用条件与权限

- Windows 10/11 x64；Android 11 或以上；可传数据的 USB 线。
- 手机安装匹配版本的 VVA，自行配置模型供应商和 API Key。VVA 免费，模型供应商仍可能收取调用费。
- 模型请求需要手机联网；手机与电脑之间走 USB，不需要注册 VVA 账号或无线远控服务。

| 要使用的功能 | 需要开启或确认什么 |
|---|---|
| 安装 APK | Android 提示时，允许本次使用的浏览器/文件管理器安装应用。 |
| 手机连接电脑 | 开发者选项内开启 **USB 调试**；解锁手机，接受该电脑的 RSA 调试授权。部分电脑需要手机厂商 USB 驱动。 |
| 操作电脑 | 启动脚本中确认本次会话，再按需同意桌面控制、执行命令；这两项分开选择。 |
| 操作手机自己的屏幕 | 开启 VVA 无障碍服务。侧载应用可能需先在系统应用设置允许受限设置。仅通过 USB 操作电脑不要求开启无障碍。 |
| 悬浮框 | 允许显示在其他应用上层。 |
| 相机问答 | 使用时授予相机权限。 |
| 长任务 | 建议允许通知，以看到运行状态和停止入口。厂商系统若限制后台，再单独允许 VVA 后台运行。 |
| 精确定时任务 | 需要时按 Android 提示允许精确闹钟。 |
| 导入图片/文件 | 通过系统文件选择器选择指定文件，不需要所有文件访问权限。 |

普通使用不需要 Root、解锁 Bootloader 或 Windows 管理员权限。完全信任与 Approve for me 不等于系统权限，也不会绕过 Windows UAC。

## 开始和结束

1. 将官方完整 U 盘包解压到可写目录或 U 盘，不能在压缩包预览里直接运行。
2. 手机安装匹配 APK。包内的 `更新手机.cmd` 使用 `adb install -r`，不会卸载应用或清除数据。
3. 手机接电脑、解锁、接受 USB 调试授权。
4. 运行 **启动.cmd**，输入 `START`，按需批准桌面/命令权限并选择正确手机。
5. 工作时保留状态窗口。按 **S** 或运行 **终止.cmd** 结束；意外关闭窗口后可运行 **清理.cmd**。这里的“终止.cmd”就是结束入口，保留原有名称。

明确需要管理员作业时，使用 `启动-管理员.cmd`，由用户确认一次 Windows UAC。普通启动保持普通权限，不安装系统服务或开机自启。

端口占用可运行 `启动.cmd -Port 18746`，结束时用 `终止.cmd -Port 18746`。不要为了腾端口终止其他程序。

正式版通过应用专属目录一次导入 USB 配对凭据，存入 Keystore 加密存储后删除临时明文；无需 `run-as` 或可调试 APK。

## 文件位置与清理

- `device-workspace/tasks/`：进度、交接。
- `device-workspace/scripts/`、`reports/`：脚本、结果。
- `device-workspace/collected/`：获授权采集的文件，不自动执行样本。
- `device-workspace/.hermes-control/`：证据、回执、断点和备份；内部旧目录名为兼容保留。
- `tools-pack-for-model/`：可编辑工具箱，完全信任时对模型开放，放入文件不会自动执行。

终止/清理不会删除工作区或手机对话。用过的 U 盘可能有私人报告和证据，转载请使用干净发布包。整理自己的工作区前先结束会话。

## 常见问题

- 找不到设备：解锁手机，检查数据线、厂商驱动及 RSA 授权；启动器不选择无线 ADB 或模拟器。
- 配对没有确认：先安装并打开匹配版本 VVA。不要把 API Key、配对 Token 发到 issue。
- 更新提示签名不一致：停止更新。旧测试版的调试签名与正式签名不同，本包不会通过卸载来解决。已有测试用户须先安排数据迁移。
- 断线：恢复后先读取当前状态及上次回执，不盲目重复提交/删除等操作。
- Windows 无法启动：阅读 `离线救援说明.md`；本包不是启动盘，不能透过已停止的 Windows 接收端控制 BIOS。
