# Third-party components — inventory in progress

VVA builds on [NousResearch/Hermes Agent](https://github.com/NousResearch/hermes-agent),
which is distributed under MIT. The original copyright and permission notice remain
with the bundled source. VVA's distribution rules do not replace that license.

Other bundled components include CPython, Android Platform-Tools, Chaquopy, AndroidX,
Google ML Kit, Python libraries, KaTeX and Marked. They retain their own licenses.
The runtime packages preserve their existing license files and distribution metadata.

Some dependencies use MPL or other licenses with additional source/notice duties.
The exact distributed versions, native/JVM artifacts and required source access
are being inventoried before public release. This page is not a declaration that
every component is MIT or that the audit is already complete.

Downloaded Microsoft Sysinternals, scanners, Geek and other vendor toolkit binaries
are not included in the public-package build. The optional toolbox catalog links
to publishers; use of downloaded tools is governed by their licenses and consent.

FlaUI-MCP ideas are credited in the companion's existing notice. Its runtime is not
silently introduced as another desktop-control service.
